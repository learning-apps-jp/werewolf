# 月あかりの人狼

公開URL：https://learning-apps-jp.github.io/werewolf/

ソース：https://github.com/learning-apps-jp/werewolf

5〜20人がタブレット1台を順番に回して遊ぶ、通常の人狼ゲームです。司会役をアプリが担当します。

## 遊ぶ

公開URLをブラウザで開いてください。ローカルでは`play.html`を開くこともできます。CSS・プログラムをまとめた1ファイルで、ローカルファイルならネット接続なしで遊べます。GitHubでは完成版をルートの`index.html`、編集用のファイルを`src/`に配置します。

1. 人数・名前・配役を設定します。
2. 端末を回し、長押しで自分の役職を開きます。
3. 初日の夜は襲撃なし。その後、全員で話し合います。
4. 順番に秘密投票し、全員集合後に結果を開きます。
5. 夜は全員に1回ずつ端末を回します。占い師は対象を選んですぐ結果を確認し、霊媒師もその場で結果を確認します。全員の手番が終わると朝になります。

基本役職：村人・人狼・占い師・騎士・霊媒師。
特殊役職：狂人・共有者・狂信者。役職人数と護衛・投票・公開ルールを調整できます。

8人の基本配役は村人3・人狼2・占い師1・騎士1・霊媒師1。特殊役職は好みに合わせて追加します。初日の占いも本人が対象を選ぶ方式が標準です。

人狼は自分の入力時に、入力済みのほかの人狼の襲撃先を見ることができます。後の順番の人ほど多くの入力を見ることになります。襲撃先は全員の手番後に最多票で決定し、同票は抽選。追加の結果確認の周回はありません。狂人・狂信者には襲撃入力を見せません。

占い・霊媒の結果は即時に渡すため、その夜に襲撃される能力者も、朝の脱落発表前に結果を確認できます。確定後の占い直しはできず、画面を隠した場合や再読み込み後も同じ結果になります。

ブラウザ内に途中のゲームと配役設定を保存します。再読み込み後はホームの「途中から再開」を押してください。終了したゲームの秘密情報は保存から削除します。端末解析や覗き見を防ぐ本人認証はありません。

## GMの代わりになる発表と案内

朝・投票結果は全員集合後に開き、短い夜明け／封を開く演出のあとで発表します。演出中に結果や得票を先出しせず、「すぐに結果を見る」でスキップできます。「動きを減らす」設定では動きを抑え、短い文言表示に切り替えます。音声読み上げは使いません。

初日の朝、襲撃による脱落、脱落者なし、追放、再投票、再同票で追放なし、同票からの抽選で文言を分けます。護衛先・護衛成功・非公開の役職は明かしません。発表文はもう一度表示でき、脱落者の参加ルールと次の行動も案内します。

投票前に全員の準備を確認する画面を設けています。議論時間が終わると投票への案内を表示しますが、自動では進めません。公開画面には現在の進行を表示し、話し合い中にルールを再確認できます。

朝は柔らかいチャイム、投票は低い打音、結果表示は短いベル、勝利発表は小さなファンファーレを鳴らします。発表の効果音は標準でオン。ホームと公開画面からオン／オフ・音量を調整でき、設定はブラウザに保存します。ブラウザが音の再生を許可しない場合も、そのままプレーできます。

議論タイマーが終了すると、全員向けの短い終了音が1回鳴ります。一時停止中は鳴りません。延長した時間が終わるともう一度鳴ります。終了後に「＋1分」を押すと、押した時点から丸1分を追加します。音量・ミュートは公開発表の設定と共通です。

個人の役職確認・対象選択・占い／霊媒の結果・秘密投票・受け渡しはすべて無音です。個人操作へ進むと、直前の発表音の余韻も止めます。結果が出る前の音は脱落の有無・陣営によって変えず、役職や未発表の結果を音から推測できないようにしています。

対象選択画面には選んだ名前と席番号を確認表示します。同名の参加者は名前に席番号を付け、投票や発表でも区別します。

## 開発と確認

- `node build.cjs`：`index.html`、`style.css`、`engine.js`、`art.js`、`audio.js`、`game.js`をまとめて`play.html`を生成。村と役職のイラストはSVG、効果音はWeb Audioで生成し、外部の画像・フォント・音声ファイルの読み込みは不要。
- `node serve.cjs`：PCのプレビューを `http://127.0.0.1:4182` で起動。
- `node verify.cjs`：勝敗・護衛・同票・夜行動・人狼間の入力表示・中断再開・秘密画面・タブレット表示を確認。UI検証はこのPCに配置されたPlaywrightとEdgeを使用。
- `node playthrough.cjs`：6人の基本、8人の基本、10人の共有者入りで勝敗まで自動操作。発表だけに音が生成されること、全個人操作が無音であること、ミュートと設定保存を検証。
- `node verify-timer.cjs`：タイマーの終了音、1回だけの通知、延長と再通知、ミュート、個人投票の無音を検証。

現版ではPIN、夜の最低操作時間、公開案内の音声、PWAインストール、スリープ防止は未実装です。遊ぶときは他人の操作を見ず、端末のスリープ時間を長めに設定してください。
